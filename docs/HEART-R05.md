# HEART R05 — Model routing
The existing private chat token remains mandatory. Configure OPENAI_API_KEY and HEART_MODEL for OpenAI; bind Workers AI as AI in Pages and set HEART_WORKERS_AI_MODEL to a compatible chat model. Choose HEART_PRIMARY_PROVIDER=openai or workers-ai. Automatic cross-provider fallback is disabled unless HEART_ALLOW_PROVIDER_FALLBACK=true; enabling it can transmit the same conversation to both providers. Explicit provider requests never fall back. No client-selected model IDs or URLs. Responses include provider/model/elapsed latency. Workers AI timeouts bound waiting but do not guarantee cancellation of upstream computation. No cost estimates or persistent telemetry yet. No change to cognitive-memory permissions; private memories are not sent automatically. Production binding, real provider tests and CI required.

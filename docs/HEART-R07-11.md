# Plugin Health
Explicit owner-approved read-only diagnostic missions use the existing plugin action and resource validation, enabled policy, atomic claim and audit. A successful probe verifies only that specific read operation, not all permissions or provider availability. HTTP status and elapsed time are recorded; tokens, response bodies and raw errors are not returned by the probe. Diagnostics require a valid resource ID (or account/tools for matching connectors). No automatic polling, generation, or paid mutation. A failed probe is recorded as failed; no automatic retry. Production credentials and real tests remain required.

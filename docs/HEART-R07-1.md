# Plugin Gateway
First external adapters: inspect allowlisted GitHub repositories owned by Motherlode94 and inspect the configured Cloudflare account. Both are read-only and require operator session, explicit mission approval and server-side configuration. Set HEART_GITHUB_TOKEN (fine-grained read-only), HEART_GITHUB_REPOS (comma-separated exact repository names), HEART_CLOUDFLARE_TOKEN (account read only), HEART_CLOUDFLARE_ACCOUNT_ID. External adapters additionally require the authenticated owner role; disable them by removing secrets. No ChatGPT plugin credentials are reused. No arbitrary URLs, mutations, OAuth or other provider adapters. Results are stored in mission history. Live credential checks, edge rate limits and deployment validation remain necessary.

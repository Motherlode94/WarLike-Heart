# Granular permissions
Apply migration 0008 before deployment. External actions deny read and diagnostic by default, even if previously enabled. Only owner can grant or revoke independently; explicit confirmation for grants. Execution claims atomically verify both plugin enablement and action permission. Revocation blocks subsequent claims, not requests already dispatched. Creation, update, deletion, publication and spending are unsupported and cannot be granted. Existing approved missions still require the matching permission at execution. Diagnostics consume the approved mission. No vendor writes or new credentials.

# Assets officiels

Le portrait officiel de WarLike Heart et sa planche de référence doivent être placés ici :

- `portrait-officiel.webp` — affichage principal.
- `planche-officielle.webp` — référence multi-vues du personnage.

Les fichiers sont préparés dans l'archive fournie dans la conversation. **Ils ne sont pas encore présents sur GitHub.** L'application n'affiche pas de visage alternatif en attendant leur importation.

Voir [ASSETS_OFFICIELS.md](../ASSETS_OFFICIELS.md).
